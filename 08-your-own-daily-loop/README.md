# Project 8 — Your Own Daily Loop

**Course goal:** Ek morning triage loop banao jo tumhare **asli** project par, asli workflows ke saath chale.
**Heartbeat:** Scheduled (Routine, har weekday 9am)
**"Done" ka matlab:** Routine 5 business days tak be-mudakhalat (unattended) chale, har subah summary post kare,
runs ke beech zero manual kaam.

## Course ke steps
1. Ek skill file likho jisme tumhare project ke **triage rules** hon.
2. Routine banao: `/schedule every weekday at 9am, run the daily-triage skill`
3. Sirf **ek repo** ka access do (poora account nahi).
4. Summary post ke liye **ek** Slack connector attach karo.
5. Pehle one-off trials chalao (`/schedule in 2 minutes`) — rehearse (Project 9).
6. Overnight bharosa karne se pehle **teen live runs** dekho.
7. Loop ne kya pakda / kya chhoda — record karo, aur wo gaps agle hafte ke liye skill mein add karo.

## Is folder mein
- `SKILL.md` — apne project ke hisaab se `<...>` placeholders bharo.
- `run-log.md` — 5 din ka log (found / missed / skill update).
